# YAARO — Meet. Talk. Connect.

Standalone Cloudflare Workers edition with Supabase authentication.

Start with [DEPLOYMENT.md](./DEPLOYMENT.md).

Public marketing, animation system, adult onboarding, fictional social demo, real D1 community, secure connection requests, live chat updates, private validated profile photos, moderation and call signaling are preserved. Supabase email/Google/phone flows are implemented and depend on actual provider configuration. Calls require a private TURN relay. No payments are connected.

This source is prepared and locally testable; no external production deployment or end-to-end provider login has been verified yet.
